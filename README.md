# Satellite Flight Operator Interview Challenge

This repository contains my submission for the Open Cosmos Satellite Flight Operator Interview Challenge.

# Contents

- **PART 1** – Flight Operational Contact Plan and procedure flow diagram
- **PART 2** – Python automation script and execution instructions
- **Presentation** – Interview presentation

The automation is a simplified simulation of the operational procedure developed for the challenge and does not interface with real spacecraft or ground-station systems.
